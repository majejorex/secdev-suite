# OWASP API Security Top 10 (2023)

Lista copiada del repositorio oficial `OWASP/API-Security`, carpeta `editions/2023/en`, comprobada el 2026-11-02. Las señales y comprobaciones son texto propio.

Aplica a cualquier backend al que hable un cliente: REST, GraphQL, callables de Firebase, Edge Functions o un BaaS con reglas. En un BaaS, las reglas de seguridad **son** la capa de API.

| ID | Riesgo | Señales en el código | Cómo comprobarlo |
|----|--------|----------------------|------------------|
| **API1:2023** | Broken Object Level Authorization (BOLA) | El handler usa un ID del cliente (`req.params.id`, `data.childId`) sin comprobar que el recurso pertenece al usuario | Test: el usuario A pide el recurso de B y recibe 403/denegado |
| **API2:2023** | Broken Authentication | Tokens sin verificar o sin caducidad; login sin límite de intentos; reset que revela si el email existe | Revisar la verificación del token en cada entrada; límite de intentos; respuesta idéntica exista o no la cuenta |
| **API3:2023** | Broken Object Property Level Authorization | Se devuelve el documento entero (`res.json(doc)`) o se acepta el body entero en un update (asignación masiva: `role`, `isVerified`, `price`) | Respuestas proyectadas con campos permitidos; updates con lista blanca de campos (`keys().hasOnly` en reglas) |
| **API4:2023** | Unrestricted Resource Consumption | Sin paginación ni límites; subidas sin tamaño máximo; llamadas caras (LLM, SMS, email) sin tope por usuario | `limit` máximo en consultas; tamaño máximo; rate limit y presupuesto por usuario |
| **API5:2023** | Broken Function Level Authorization | Funciones de admin accesibles para usuarios normales; el rol se lee del cliente | Test: un usuario normal llama a la función de admin y recibe denegado |
| **API6:2023** | Unrestricted Access to Sensitive Business Flows | Flujos de negocio automatizables sin freno (reservas, cupones, invitaciones, altas) | Límites por flujo, anti-bot, detección de patrones |
| **API7:2023** | Server Side Request Forgery (SSRF) | El servidor hace fetch de una URL que da el usuario (previews, webhooks configurables, importaciones) | Lista permitida de hosts; bloquear IPs privadas y `169.254.169.254`; sin seguir redirecciones a internos |
| **API8:2023** | Security Misconfiguration | CORS `*` con credenciales; debug activo; errores con stack trace; cabeceras ausentes; reglas abiertas | Revisar la configuración de CORS, cabeceras, reglas y respuestas de error |
| **API9:2023** | Improper Inventory Management | Endpoints o funciones viejas desplegadas; entornos de prueba públicos; versiones de API sin retirar | Inventario de lo desplegado frente al código; borrar lo huérfano |
| **API10:2023** | Unsafe Consumption of APIs | Se confía en respuestas de terceros sin validar; webhooks sin firma; sin timeouts | Validar respuestas de terceros; firma de webhooks; timeouts y reintentos acotados |
