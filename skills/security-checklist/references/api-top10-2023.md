# OWASP API Security Top 10 (2023)

List copied from the official `OWASP/API-Security` repository, folder `editions/2023/en`, checked on 2026-11-02. The signals and checks are our own text.

Applies to any backend that a client talks to: REST, GraphQL, Firebase callables, Edge Functions or a BaaS with rules. In a BaaS, the security rules **are** the API layer.

| ID | Risk | Signals in the code | How to check |
|----|------|---------------------|--------------|
| **API1:2023** | Broken Object Level Authorization (BOLA) | The handler uses a client-supplied ID (`req.params.id`, `data.childId`) without checking that the resource belongs to the user | Test: user A requests B's resource and gets 403/denied |
| **API2:2023** | Broken Authentication | Tokens not verified or without expiry; login without an attempt limit; reset that reveals whether the email exists | Review token verification at every entry point; attempt limit; identical response whether or not the account exists |
| **API3:2023** | Broken Object Property Level Authorization | The whole document is returned (`res.json(doc)`) or the whole body is accepted in an update (mass assignment: `role`, `isVerified`, `price`) | Responses projected to allowed fields; updates with a field allowlist (`keys().hasOnly` in rules) |
| **API4:2023** | Unrestricted Resource Consumption | No pagination or limits; uploads without a maximum size; expensive calls (LLM, SMS, email) without a per-user cap | Maximum `limit` on queries; maximum size; rate limit and budget per user |
| **API5:2023** | Broken Function Level Authorization | Admin functions reachable by normal users; the role is read from the client | Test: a normal user calls the admin function and gets denied |
| **API6:2023** | Unrestricted Access to Sensitive Business Flows | Business flows that can be automated with no brake (bookings, coupons, invitations, sign-ups) | Limits per flow, anti-bot, pattern detection |
| **API7:2023** | Server Side Request Forgery (SSRF) | The server fetches a URL given by the user (previews, configurable webhooks, imports) | Host allowlist; block private IPs and `169.254.169.254`; do not follow redirects to internal hosts |
| **API8:2023** | Security Misconfiguration | CORS that reflects any `Origin` (or accepts `null`) with `Access-Control-Allow-Credentials: true` (the browser already blocks `*` with credentials); debug on; errors with stack traces; missing headers; open rules | Review the CORS configuration, headers, rules and error responses |
| **API9:2023** | Improper Inventory Management | Old endpoints or functions still deployed; public test environments; API versions not retired | Inventory of what is deployed against the code; delete what is orphaned |
| **API10:2023** | Unsafe Consumption of APIs | Third-party responses trusted without validation; webhooks without a signature; no timeouts | Validate third-party responses; webhook signatures; bounded timeouts and retries |
