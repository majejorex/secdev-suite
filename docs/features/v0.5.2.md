# v0.5.2: marketplace and plugin metadata, call skills by name (2026-11-03)

## Problem

The marketplace described itself as "Private" although the repo is public, the plugin had no `repository` or `homepage`, the README did not say how to call a skill by name when it does not activate, and the PostToolUse section did not list the `SECURITY-PROFILE.md` reminder. `v0.5.1` still ships `intel-review` to the skills installer; this release does not.

## Changes

- `marketplace.json`: public description. `plugin.json`: `homepage` and `repository`.
- README (EN and ES): "Calling a skill by name" (`/secdev:security-checklist`, or `security-checklist` / `$` when installed standalone) and the profile category in the PostToolUse list.
- Includes `maintainer/intel-review/` (moved out of `.claude/skills/`), so `npx skills add` lists only the three skills.

## Not done

- Per-hook `description` fields in `hooks/hooks.json`: the hooks are described in the top-level `description`, the README and the header of each `.mjs`; I did not verify that Claude Code accepts a description on each entry.

## Updating

```sh
git diff v0.5.1..v0.5.2 -- hooks/ .claude-plugin/
```
