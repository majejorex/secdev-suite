# v0.5.1: v0.5.0 plus install-as-skill and small fixes (2026-11-03)

## Problem

The `v0.5.0` tag was pushed by mistake on the commit before the release (`7aad3f3`, plugin version 0.4.5), and tags cannot be moved. The real release is this one. Do not use the `v0.5.0` tag.

## Changes

- Everything described in [v0.5.0](v0.5.0.md).
- **Skills install in any agent** (`npx skills add majejorex/secdev-suite --skill security-checklist --skill security-fix --skill security-gate`). `security-fix` and `security-gate` had an unquoted `: ` in their description, which strict YAML parsers rejected; they now use a folded block, and the structure test rejects the old form.
- **Skills name each other by folder name** (the plugin name `secdev:...` stays where a skill must be loaded).
- **Edits to `SECURITY-PROFILE.md` trigger the reminder** (`hooks/risk.mjs`, controls P0-10, P0-11, P1-07).
- **CI also runs the tests on Windows** (job `test-windows`; the job `test` stays single because it is a required check).
- The checklist now says to call reviewer-aimed text "prompt injection" (eval `injection-comment` went from 2/3 to 3/3; see `docs/evals/v0.5.0.md`).

## Not done

- `stack.mjs` scans only the first 30 subfolders in disk order (documented as a `shortcut:`).
