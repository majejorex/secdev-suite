# v0.4.5: the hook cleans up after itself (2026-11-03)

## Problem

The `PostToolUse` hook leaves one empty file per session in `secdev-sessions`, in the system temp folder, so it warns only once per session. Nothing deleted them. After one day of use there were 144 files.

## Changes

- **`hooks/post-edit.mjs`.** When it creates a new mark, it deletes the `.reminded` marks older than 7 days. It scans at most 1000 entries, touches only files that end in `.reminded`, and ignores any error. It runs once per session with a risky edit, so the time stays under 1 second and the reminder is never delayed or lost.
- **Test.** An 8-day-old mark is deleted, a 1-day-old mark and an unrelated file stay, the reminder is still printed and the hook finishes in under 1 second.
- **`.gitignore`** now lists `.playwright-mcp/` and `.superpowers/`, the folders that browser and planning tools create, so they are not committed by mistake.

No change in the skills, so no evals were needed.
