# secdev v0.3.0 (English base, hook fixes, `check`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.3.0. Everything is in English, `security-checklist` is renamed to `check` with a compact report and a reachable PASS, the hook gaps found in the 2026-11-02 audit are fixed, the evals are broader, and a weekly job flags stale OWASP sources.

**Architecture:** The plugin layout stays as it is (`skills/`, `hooks/`, `evals/`, `test/`). There is one new single source, `core/checklist.md`, which `scripts/sync-checklist.mjs` copies between markers into `skills/check/SKILL.md`. The hooks stay pure modules (`stack.mjs`, `risk.mjs`) with thin entry points. The reminder entry point handles three events (PostToolUse, PreToolUse:Skill, UserPromptExpansion).

**Tech Stack:** Node ≥ 20, ESM `.mjs`, `node:test`, zero dependencies.

**Spec:** `docs/design/2026-11-02-suite-design.md`. The full approved plan is at `~/.claude/plans/evolve-secdev-suite-into-the-indexed-eclipse.md` (Spanish).

## Global Constraints

- `npm test` must be green before every commit. No dependencies.
- Hooks always `exit 0`, take < 1 s, print ≤ 5 lines, and stay silent when there is nothing to say. Every hook change gets a test.
- `SKILL.md` stays under 150 lines. Frontmatter `name` equals the folder name.
- OWASP IDs and titles are never written from memory. Keep the existing IDs exactly as they are in today's files and translate only our own prose.
- Hook output names only fixed category strings and never repo text.
- Never `git push` and never tag. The maintainer reviews the `hooks/` diff first, and approves any eval run because evals cost money.
- Commit identity is already set in `git config --local`. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Verdict tokens: `BLOCK | PASS WITH ISSUES | PASS`. Stack tag `mobile` (formerly the Spanish `móvil`).

## Review Focus

1. **Windows paths:** backslash paths for the new path rules (`android\app\src\main\AndroidManifest.xml`, `.github\workflows\ci.yml`) are classified the same as forward-slash paths. Test in Task 4.
2. **Huge monorepos:** `packages/` with 200 children must stay under the `MAX_CHILD_DIRS` total cap and under 1 s. Test in Task 3.
3. **Concurrency:** two PostToolUse processes racing on the same session produce exactly one reminder (`wx` and `EEXIST` mean already reminded). Any other fs error stays silent. Test in Task 5.
4. **Missing `session_id`:** a re-arm or reminder input without `session_id` is a no-op for re-arm. The reminder still prints, as today. Test in Task 5.
5. **CRLF checkouts:** the checklist sync comparison ignores `\r\n` vs `\n`, so a Windows checkout does not fail the sync test. Test in Task 1.
